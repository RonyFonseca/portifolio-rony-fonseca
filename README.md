# Portfólio — Rony Fonseca

Portfólio pessoal com foco em desenvolvimento Full Stack, Engenharia de Software, projetos e experiência profissional.

## Identidade visual

A versão atual usa uma estética **100% dark**, baseada em diferentes tons de preto, grafite, branco e cinza. A foto profissional em `assets/imgs/eu-fundo-estudio.jpg` é apresentada em um enquadramento circular no hero.

## Estrutura

- `index.html` — estrutura e conteúdo
- `assets/style/style.css` — identidade visual e responsividade
- `assets/js/script.js` — menu mobile, filtros, animações e progresso de scroll
- `assets/imgs/` — imagens utilizadas no projeto
- `assets/documents/cv.pdf` — currículo

## Recursos

- Layout responsivo
- Hero profissional com terminal visual
- Foto de perfil circular
- Timeline de experiência
- Projetos sem imagens, priorizando descrição, stack e links
- Filtros de projetos
- Stack tecnológica
- CTA de contato
- Animações de entrada
- Barra de progresso de leitura
- Menu mobile
- Acessibilidade básica e `prefers-reduced-motion`

## Tecnologias

HTML5, CSS3 e JavaScript puro.
